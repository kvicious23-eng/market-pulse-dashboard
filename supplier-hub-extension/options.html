연결 상태 확인 중

아침 가격 수집 완료 뒤 연결을 시작하고, Chrome이 실행 중이면 15분마다 확인해. 추가 인증이나 로그인 실패가 나오면 반복 입력을 멈춰. 비밀번호를 바꾼 뒤에는 ‘연결 확인’을 눌러줘.

프리미엄 데이터 2.0
같은 Chrome 프로필의 로그인 세션으로 페이지를 열어. 로그인 연결 상태와 이 화면의 판독 결과는 따로 확인해.
아직 화면 확인 전


매일 아침 CSV 자동 갱신
08시 가격 JSON 저장 완료 → 인증 확인·필요 시 재로그인 → 전체 데이터 다운로드 → 전일·당월 범위 검증 → 게시. CSV가 늦게 완료되면 세 가지 합계만 추가 게시해.
아직 아침 완료 신호를 기다리는 중이야.
하루 한 번 요청하며 중단된 요청은 다운로드 기록에서 복구해. 추가 인증·잘못된 기간·불명확한 다운로드는 상태를 남겨. 정상 가격 게시와는 별개로 처리해.


CSV 다운로드·PC에서 읽기
수동 요청이야. 아침 자동 요청이 진행 중이면 중복 클릭을 막아.




CSV를 선택하면 PC 안에서 열 구조와 원본 행을 읽어.


Market Pulse 등록 상품과 대조
가격 수집 확장의 목록 저장 시 다운로드되는 파일이야. 상품 추가·삭제 후에는 최신 파일을 선택해.


Market Pulse 상품 관리의 SKUID를 처음 한 번 등록·저장하고 최신 카탈로그를 선택해. 이후에는 저장한 코드를 그대로 사용해. CSV의 SKU ID 또는 SKUID 열이 하나이면 기본으로 선택해. 미등록 ID는 상품명으로 자동 대체하지 않아.
파일은 이 관리 화면에서만 처리해. 행을 합산하거나 없는 상품의 재고를 0으로 처리하지 않아. 원본 파일을 유지하며 가공본은 따로 저장해.


연결 기록
    

    계정은 Windows 자격 증명 관리자에 저장돼. 선택한 CSV는 PC에서 처리하며 GitHub·공개 대시보드·서버로 전송하지 않아.

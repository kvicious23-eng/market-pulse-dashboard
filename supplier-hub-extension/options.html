연결 상태 확인 중

Chrome이 실행 중일 때 15분마다 확인해. 추가 인증이나 로그인 실패가 나오면 반복 입력을 멈춰. 비밀번호를 바꾼 뒤에는 ‘연결 확인’을 눌러줘.

판독 진단


연결 기록
    

    계정 입력은 PC 설정 창에서 처리하며 Windows 자격 증명 관리자에 저장돼. 이 화면에는 비밀번호가 표시되지 않아. 이번 버전은 로그인 연결 검증용이며 재고 수집·대시보드 게시를 실행하지 않아.
